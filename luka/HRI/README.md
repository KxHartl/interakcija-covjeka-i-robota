# Human Robot Interaction – Exercises 1 & 2

This repository contains code and resources for the Human Robot Interface exercises 1 and 2.

## Contents

- Exercise 1: Getting familiar with YOLO-pose, Keypoint extraction, Basic body distance estimation.
- Exercise 2: YOLO-pose on RealSense, Depth measurement of body keypoints.

## Requirements

 ```bash
 pip install -r requirements.txt
 ```
